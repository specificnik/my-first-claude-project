# My First Claude Project

A minimal sample repository created with Claude Code.

## Contents

- `hello_claude.py` — a small script that prints a greeting.
- `ask_claude.py` — sends a real prompt to the Claude API and prints the response.
- `requirements.txt` — Python dependencies (the `anthropic` SDK).

## Usage

```bash
python hello_claude.py
```

### Calling the Claude API

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="your-api-key"
python ask_claude.py "What is Claude Code?"
```
